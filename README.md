# 医療費控除いくら？（iryohi-ikura）

1年間に払った医療費の場面（通院のバス代・ビタミン剤・保険の給付金・所得が少ない人・セルフメディケーション税制 など）を読んで、医療費控除の額を当てる1日5問の学習ゲーム。正解したら「どの計算？」（10万円を引く・所得の5％・最高200万円・控除なし・セルフメディケーション）も選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/iryohi-ikura/>

- 答えは、国税庁タックスアンサーの計算（対象の医療費−保険金などの補てん−10万円、最高200万円。総所得金額等が200万円未満なら10万円の代わりにその5％。セルフメディケーション税制は対象の薬の購入費−12,000円、最高88,000円）と、対象になる医療費の決まりから出しています（［令和8年4月1日現在法令等］。2026-11-17 に読みました）。
  - No.1120 医療費を支払ったとき（医療費控除） <https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1120.htm>
  - No.1122 医療費控除の対象となる医療費 <https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1122.htm>
  - No.1129 セルフメディケーション税制 <https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1129.htm>
- 所得が書いていない場面は、総所得金額等が200万円以上の人です。出産・眼鏡・人間ドックのあとの治療・申告の手続きは出しません。人と金額はつくりものです。
- このゲームは医療費控除のしくみを知る練習です。税の相談の代わりではありません。実際の控除の額は、国税庁の資料や税務署で確かめてください。
